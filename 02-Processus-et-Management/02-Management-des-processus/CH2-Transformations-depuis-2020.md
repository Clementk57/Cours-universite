## Les modèles de langage spécialisés

C’est une autre tendance directement liée aux agents.

Gartner indique que les **modèles de langage spécialisés dans un domaine** apportent davantage de précision et de conformité.

Un agent n’est donc pas nécessairement associé à un seul gros modèle généraliste.

### Exemples d’association entre agents et modèles

```text
Agent juridique
    → modèle juridique

Agent programmation
    → modèle spécialisé code

Agent finance
    → modèle financier

Agent extraction
    → modèle ou modèle documentaire spécialisé
```

Dans une architecture multi-agents, chaque agent peut même utiliser un modèle différent.

## Les tendances observées

### Tendance 1 — Une plateforme pour tout faire

Une plateforme unique peut regrouper plusieurs usages et plusieurs capacités.

### Tendance 2 — Un dossier de contexte pour l’IA

Un dossier ou un « folder » peut être utilisé pour donner davantage d’informations à l’IA.

### Tendance 3 — Le Confidential Computing

Le **Confidential Computing** vise à préserver la confidentialité des données pendant leur traitement.

> [!important] Enjeu
> Le niveau de traitement des données doit rester privé.

### Tendance 4 — Les systèmes multi-agents

Les systèmes multi-agents reposent sur une grande quantité d’agents qui peuvent coopérer comme une ruche.

> [!note] Architecture multi-agents
> Un agent peut utiliser un modèle spécialisé différent de celui des autres agents.

### Tendance 5 — Les modèles de langage spécialisés

Une IA peut être spécialisée dans un domaine donné.

Cette tendance rejoint l’idée qu’un agent juridique, un agent de programmation, un agent financier ou un agent d’extraction peut utiliser un modèle adapté à son domaine.

### Tendance 6 — L’IA physique

L’IA physique concerne notamment la robotique, à la maison ou dans les entreprises.

### Tendance 7 — La cybersécurité préventive

La cybersécurité préventive défend une approche proactive qui s’appuie sur l’IA contre l’IA.

> [!danger] Risque à anticiper
> Les outils d’IA peuvent être utilisés pour attaquer. La défense doit donc également anticiper et agir en amont.

### Tendance 8 — La provenance des données numériques

La provenance des données numériques concerne les données générées, notamment les données que l’IA retourne.

Une question se pose alors : l’IA dispose-t-elle de suffisamment d’intelligence et d’informations pour produire des données fiables ?

> [!question] Question de confiance
> Il faut pouvoir comprendre d’où viennent les données et évaluer la qualité des informations retournées par l’IA.

### Tendance 9 — Les plateformes de sécurité dédiées à l’IA

Les plateformes de sécurité dédiées à l’IA offrent une **supervision unifiée** et un **contrôle centralisé** des applications d’IA.

### Tendance 10 — La géopatriation

Le concept de **géopatriation** permet aux entreprises d’atténuer les risques en transférant leurs...

> [!warning] Information incomplète dans la prise de notes
> La phrase d’origine s’arrête après « en transférant leurs ». Aucun complément n’est ajouté afin de conserver la base sans inventer d’information.

## À retenir

- Les tendances technologiques concernent à la fois les personnes, les espaces intelligents, les données, l’IA et la sécurité.
- Les agents peuvent utiliser des modèles de langage spécialisés selon leur domaine.
- Les architectures multi-agents permettent à plusieurs agents de coopérer, avec éventuellement un modèle différent pour chacun.
- La confidentialité, la cybersécurité préventive, la provenance des données et la supervision deviennent des enjeux centraux.
- La veille technique permet de suivre les changements dans un environnement où tout évolue rapidement.

> [!tip] Remarque finale
> Il faut rester vigilant parce que tout va très vite.
